Cross Attention Custom Notes:
    Query: Current Frame
    Key: Reference Frames
    Value: Reference Frames

    Cross attention is used to condition the diffusion model on the reference frames.
    The query is the current frame, and the key and value are the reference frames.
    This allows the model to attend to the reference frames and use their information to generate the current frame.
